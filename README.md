# AethelMind-CADD

AethelMind-CADD is a modular, high-performance web interface designed for in-silico hybrid molecular generation, property prediction, and interactive 3D conformational visualization.

## Engineering Stack
* Frontend Orchestration: Streamlit Cloud Engine
* Cheminformatics Layer: RDKit (Conformer Embeddings & Energy Refinements)
* Machine Learning: Scikit-learn (Isolation Forest)
* Graphic Pipeline: WebGL via py3Dmol & stmol wrappers
